No data collected

Privacy Policy

Bookmark Dashboard & the Bookmark Suggestions browser extension · Last updated September 2, 2026

The short version: this project does not collect, transmit, sell, or share any of your data, because it has no server to send it to. Everything — your bookmarks, your automatic-suggestion settings, and the pages the extension has noticed — stays inside your own browser, on your own device.

What data exists, and where it lives

  • Your bookmarks (title, URL, category, notes, favorite flag) are stored in the dashboard page's own localStorage, in the browser you opened it in.
  • Automatic-suggestion data (pending suggestions, dismissed URLs, your settings like pause state or dedupe mode) is stored in the extension's chrome.storage.local, which is private to your browser profile and this extension.
  • The dashboard page and the extension exchange this data with each other, on your device only, through the browser's own messaging APIs.

What we don't do

  • No servers. There is no backend anywhere in this project — nothing to send data to even if we wanted to.
  • No accounts, sign-ups, emails, or passwords.
  • No analytics, telemetry, crash reporting, or usage tracking of any kind.
  • No advertising, and no data is ever sold or shared with any third party.
  • No browsing history is recorded. The extension only looks at the URL, title, and favicon of the tab currently in front of you, decides in real time whether it's worth suggesting, and — if not — forgets it immediately.

Permissions the extension requests, and why

  • tabs — to read the URL, title, and favicon of the active tab so it can decide whether to suggest it as a bookmark. The extension does not read page content and has no host_permissions to inject scripts into the sites you visit.
  • storage — to save your suggestions, dismissed list, and settings locally via chrome.storage.local, so they persist between browser sessions on this device.

That's the complete permission list. No host_permissions, no scripting, no webNavigation, no history, and no access to incognito windows unless you explicitly turn it on in both the browser's extension settings and the dashboard.

Favicons

Suggestion cards may load a small favicon image directly from the site it belongs to (or from an embedded data: image), using referrerpolicy="no-referrer" so the request doesn't leak which page referred it. This is the same as your browser tab already does when showing that site's icon — no separate service is involved.

Your data, your control

  • Uninstalling the extension or clearing your browser's site data for the dashboard removes all stored data immediately — there is nothing left on any server to delete, because none exists.
  • Bookmarks, suggestions, and settings are local to one browser profile on one device. They are never synced anywhere by this project (your browser's own built-in sync, if enabled, is a separate feature outside this project's control).

Changes to this policy

If this project ever adds a feature that changes any of the above (for example, an optional server-based sync), this page will be updated first and the "Last updated" date at the top will change accordingly.

Contact

Questions about this policy or the project can be raised via the project's GitHub repository (issues) once it's public, or by contacting the developer directly.
